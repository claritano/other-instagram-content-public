# other-instagram-content-public

Temporary public image host for the @bureauofsmallproblems daily carousel.

Instagram's Graph API fetches carousel images over HTTPS, so the five JPEGs are
pushed here for the minutes it takes to create the containers and publish. The
publishing run then replaces this branch with a single commit containing this
file alone.

An image here is in flight. An empty repository is the normal state.

Published and generated content lives in Cloudflare D1, written by
[claritano/other-instagram-accounts](https://github.com/claritano/other-instagram-accounts).
